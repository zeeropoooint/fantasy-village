# 玩家操作指南 · Fantasy Village（西幻生活模拟）

欢迎来到小村庄！这份指南告诉你怎么玩，不需要懂任何技术，两分钟就能上手。

---

## 移动

| 设备 | 操作方式 |
| --- | --- |
| 键盘 | `W` `A` `S` `D` 或 方向键 ↑↓←→ |
| 手机/触屏 | 按住**屏幕左下角的虚拟摇杆**，往想走的方向拖动即可 |

松开摇杆角色就停下，斜着拖也能走斜线。

## 与世界互动

靠近床、门、木牌、NPC 这类东西时，**右下角会弹出交互按钮**，按钮上会显示目标的名字（比如「睡觉」「对话」）。

| 设备 | 操作方式 |
| --- | --- |
| 键盘 | `空格` 或 `E` |
| 手机/触屏 | 点右下角的交互按钮 |

只要按钮没出现，就说明周围没有可以互动的东西，再走近一点试试。

## 聊天

- 对话是逐字打出来的，再按一次**互动键**（`空格`/`E`）或点一下屏幕就能跳到下一句。
- 出现**选项分支**时，直接点击你想说的那句话。
- 按 `Esc` 可以关闭/退出对话。

## 节奏小游戏

在村庄里接到的第一个小游戏是「节奏点击」：

- 音符出现时，按互动键（`空格`/`E`）或点击屏幕击打。
- 5 个音符击中 3 个以上，奖励 **30 金币**；没达标也有 10 金币安慰奖。

## 睡觉过天

- 走到床边按互动键，选择睡觉，就会跳到第二天早上 6:00。
- 每天睡觉时会**自动存档**，下次打开游戏从存档继续。

## 屏幕上的小图标（HUD）

- **左上角**：当前金币数量和时间（第几天 + 几点）。
- 时间会随你走动流逝，晚上别忘了回家睡觉~

## 快速上手路线

1. 醒来后走下床边的位置，按互动键起床。
2. 走到门口互动，出门进入村庄。
3. 去找药剂师聊聊，或者看看木牌上写了什么。
4. 尝试一把节奏小游戏赚点金币。
5. 玩累了回屋上床睡觉，自动存档，迎接新的一天！
